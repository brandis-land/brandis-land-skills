## Maintenance

- Use the user’s explicit words when possible.
- Mark an inference as tentative and ask before saving it.
- Preserve dated contradictions until the user resolves them.
- Update only the affected fields rather than rewriting the entire profile.
- Add a working rule only after the user approves it or a repeated outcome supports it.
- Encourage the user to remove stale details and sensitive information.
